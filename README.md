# Menco (Mentor Connector)

지역 청소년과 대학생 선배를 **고민 기반**으로 연결하는 1:1 진로·학습 멘토링 플랫폼 (MVP 데모)

## 실행

```bash
npm install
npm run dev   # http://localhost:3000
```

## 구성

- Next.js 15 (App Router) + TypeScript, 백엔드 없이 브라우저 localStorage에 저장 (`lib/store.ts`)
- 조건 기반 매칭 (`lib/match.ts`): 관심 분야 +3 · 고민 유형 +3 · 관심 전공 +2 · 경험 분야 +2 · 시간 겹침 +1
- 가상 멘토 데이터 8명 (`lib/data.ts`)

## 멘토 경력 조회 확인 (시연 버전)

1. 멘토가 프로필을 저장하면 성범죄 경력·아동학대관련범죄 전력 조회 동의서 화면으로 이동해요.
2. 필수 동의 2개, 서명(프로필 이름), 조회 결과 PDF를 제출하면 상태가 **확인 대기**가 돼요.
   - 개인정보 보호를 위해 **파일 내용은 저장하지 않고 파일 이름만** 기록해요. 실제 서류는 올리지 마세요.
3. 운영자 페이지(`/admin`, 푸터 링크)에서 **확인 완료** 또는 **반려(사유 입력)**를 해요.
4. 확인 완료된 멘토만 멘토 목록·추천·신청 화면에 나오고, "경력 조회 완료" 배지가 붙어요. 반려되면 멘토가 마이페이지에서 다시 제출할 수 있어요.

- 운영자 코드 기본값은 `admin`이에요. 바꾸려면 환경변수 `NEXT_PUBLIC_ADMIN_CODE`를 설정하세요. 화면 진입만 막는 시연용 장치이고 실제 보안 수단은 아니에요.
- 데이터가 브라우저에 저장되므로 멘토 가입과 운영자 확인은 **같은 브라우저**에서 해야 보여요.
- 동의서 문구는 시연용 양식이에요. 실제 운영 전에는 검토가 필요하고, 조회는 조회 자격이 있는 기관을 통해 진행하는 방식을 검토해야 해요.

## 멘토·학생 1:1 채팅 (시연 버전)

- 멘토링 신청 1건마다 채팅방이 하나 생기고, **멘토가 승인한 뒤부터** 마이페이지의 "💬 채팅" 버튼으로 들어갈 수 있어요. 첫 말풍선에는 신청 내용이 보여요.
- 안 읽은 메시지 수가 채팅 버튼에 표시돼요.
- 미성년자 보호를 위해 전화번호로 보이는 내용은 보낼 수 없고, 카톡·인스타 등 외부 메신저 이야기가 나오면 주의 안내가 떠요.
- 대화는 이 브라우저에만 저장돼요. 시연할 때는 로그아웃 후 상대방 계정으로 로그인해서 답장하면 돼요. 서로 다른 기기끼리 실시간으로 채팅하려면 서버(DB)가 필요해요.

## AI 수업 요약 (시연 버전)
화상 멘토링 방의 "AI 수업 요약"에서 녹음을 끝내면, 서버(`app/api/summarize/route.ts`)가 OpenAI로 음성을 글로 바꾸고 요약해서 돌려줍니다. 요약은 신청 건에 저장되어 마이페이지 "AI 수업 요약 보기"에 나옵니다.

- **키 설정:** `.env.example`을 복사해 `.env.local`을 만들고 `OPENAI_API_KEY`를 채웁니다. 배포(Render)에서는 Environment에 같은 이름으로 넣습니다. 키는 서버에서만 읽으며 브라우저로 내려가지 않습니다. 키가 없으면 요약 버튼이 안내 문구를 보여주고 나머지 기능은 그대로 동작합니다.
- **모델:** 기본은 음성 인식 `gpt-4o-mini-transcribe`(없으면 `whisper-1`), 요약 `gpt-4o-mini`입니다. `OPENAI_TRANSCRIBE_MODEL`, `OPENAI_MODEL`로 바꿀 수 있습니다.
- **개인정보:** 녹음 전에 동의 체크가 필요하고, 음성 파일과 받아쓴 원문은 저장하지 않으며 요약 글만 남습니다. 음성은 요약 과정에서 OpenAI 서버로 전송됩니다.
- **한도:** 한 번에 90분 이내(24MB), 같은 IP에서 10분에 10번까지 요청할 수 있습니다.
- **시연 제한:** 실제 상대방과 연결되지 않으므로 이 기기의 마이크로 들리는 소리만 녹음됩니다.

## 지역 반영과 경험 중심 추천 (시연 버전)
- **출신 지역:** 멘토는 프로필에서 출신 지역(고등학교를 다닌 지역)을 필수로 고릅니다. 학생 지역과 같으면 추천 점수 +2와 "같은 지역 출신" 이유가 붙고, 카드와 상세에 "📍 강원 출신"이 표시됩니다. (시드 멘토의 출신 지역은 시연용 가상 데이터입니다.)
- **내 고민 ↔ 선배의 경험:** 추천 카드에 학생의 고민 한 줄과 멘토의 경험 한 줄을 나란히 보여줍니다.
- **AI 추천 설명:** `app/api/recommend-reasons/route.ts`가 고민과 멘토 경험을 읽고 "왜 이 선배인지"를 2문장 이내로 씁니다. 학생 이름과 연락처는 보내지 않고, 같은 고민·같은 멘토 조합은 브라우저에 저장해 다시 요청하지 않습니다. 키가 없거나 OpenAI 호출이 실패하면 AI 문장만 빠지고 나머지 추천은 그대로 보입니다.

## 멘토 경험 구조화 (시연 버전)
진학을 고민하는 학생에게 가장 필요한 "전공·대학생활의 실제 모습"을 자유 글이 아닌 항목으로 받습니다.
- **입력 항목(멘토 프로필):** 전공 만족도(1~5), 입학 전에는 몰랐던 점, 적응하면서 힘들었던 점, 이런 학생에게 잘 맞아요(선택), 전공을 바꾼 경험(학과 옮김·복수전공·전공 재선택 포함). 앞의 세 항목은 필수입니다.
- **표시:** 멘토 상세 페이지의 "전공·대학생활, 실제로는 이랬어요", 카드의 "입학 전 몰랐던 점"과 "🔄 전공을 바꾼 경험" 배지.
- **매칭:** 학생이 "전공 선택"을 고민 주제로 고르면 전공을 바꾼 경험이 있는 멘토에게 +1과 이유가 붙습니다.
- **AI 설명:** 이 항목들도 추천 이유를 쓸 때 근거로 전달됩니다. 표현은 범죄 기록과 혼동되지 않도록 "전과"가 아니라 "전공을 바꾼"으로 통일했습니다.
- 시드 멘토 24명의 항목은 시연용 가상 데이터입니다.

## 멘토링 시간과 비용 (시연 버전)
- **1회 30분, 이용료 9,900원 고정.** 모든 멘토가 같은 금액이며 멘토와 학생이 가격을 협상하지 않습니다. 금액과 시간은 `lib/data.ts`의 `SESSION_PRICE`, `lib/schedule.ts`의 `SESSION_MINUTES`에서 한 번에 바꿀 수 있습니다.
- 멘토는 시간표를 1시간 칸으로 체크하고, 학생은 한 칸에서 30분 멘토링을 2회(예: 19:00~19:30, 19:30~20:00) 고를 수 있습니다. 예약된 30분은 다른 학생이 고를 수 없습니다.
- 이용료는 신청 화면, 멘토 상세, 학생 마이페이지에 표시되고 신청 당시 금액이 신청 건에 저장됩니다. **시연 화면이라 실제 결제는 이루어지지 않습니다.**

## 멘토 입시·성적 정보와 후기 (시연 버전)
- **입시·성적 정보(멘토 프로필, 본인 입력):** 거친 입시 전형(수시 학생부교과·학생부종합·논술·실기, 정시, 기타), 고등학교 내신 등급 평균(소수점까지 입력, 1~9), 대학 학점(선택 공개, 비우면 공개하지 않음). 멘토 상세에 "본인 입력"으로 표시하며 서류로 확인된 정보가 아닙니다. **내신·학점은 추천 순서와 점수에 쓰이지 않습니다.**
- **전형 매칭:** 학생이 "준비하는 입시 전형"을 고르면 같은 전형을 거친 멘토에게 +2가 붙습니다. AI 추천 설명에는 전형 이름만 전달하고 성적 숫자는 전달하지 않습니다.
- **후기:** 완료된 멘토링 1건에 학생이 후기를 1개 남길 수 있습니다(별점, 도움이 된 점, 한 줄). 학생 이름은 공개하지 않고 "강원 고1 학생"처럼 표시합니다. **후기가 2개 이상일 때부터 평균 별점을 보여주고**, 그 전에는 후기 개수만 보여줍니다(`MIN_REVIEWS_FOR_AVERAGE`).
- 시드 멘토 24명의 입시·성적 정보와 일부 멘토(박서준, 김지은, 정유나, 한도윤, 이하늘, 정민재)의 후기 15개는 **시연용 가상 데이터**이며 후기에는 "예시 후기"가 표시됩니다.

## 멘토 재학 인증 (시연 버전)

- 멘토 인증 화면(`/mentor/verify`)에서 **① 재학 인증**(재학증명서·성적증명서 PDF)과 **② 경력 조회 동의**를 각각 제출해요. 경력 조회와 같은 방식으로 파일 이름만 기록하고 내용은 저장하지 않아요.
- 운영자 페이지의 "인증 서류 확인" 탭에서 두 항목을 따로 확인 완료하거나 반려할 수 있어요.
- **두 항목이 모두 확인 완료**된 멘토만 학생에게 공개·추천되고, 카드에 "✓ 재학 인증 완료", "✓ 경력 조회 완료" 배지가 붙어요.

## 문의하기

- 마이페이지의 "문의하기"에서 멘토·학생 누구나 운영자에게 **문의**하거나 멘토링 중 겪은 **피해를 신고**할 수 있어요.
  - 신고는 피해 유형, 관련 멘토링(선택), 요청하는 처분을 함께 적어요. 위급한 경우 112, 청소년 상담 1388 안내가 보여요.
- 운영자 페이지의 "문의·신고" 탭에서 답변을 등록하고, 신고는 처리 결과(경고·활동 정지 등)도 함께 남겨요. 답변 대기·신고가 위에 정렬돼요.
- 작성자는 "내 문의 내역"에서 답변과 처리 결과를 확인하고, 새 답변이 오면 마이페이지에 "새 답변" 표시가 떠요.

## 수업 중 부적절한 표현 감지와 운영자 알림 (시연 버전)
수업 녹음을 요약할 때 같은 AI 호출에서 대화에 부적절한 표현이 있는지도 함께 판단합니다(추가 호출 없음).
- **감지 유형:** 비속어·욕설, 모욕·괴롭힘, 성적 표현, 폭력·위협, 자해·위기, 연락처·개인정보 요구, 기타 부적절. 맥락을 보고 판단하며(학술 용어나 주의를 주려고 인용한 표현은 제외), 자해·위기는 자동으로 "긴급"으로 분류합니다.
- **운영자 페이지 "안전 알림" 탭:** 긴급, 새 알림 순으로 보이고 문제가 된 발언 일부, 사유, 유형을 확인해 "확인 완료" 또는 "오탐으로 처리"를 누릅니다. AI의 자동 판단이므로 사람이 확인하는 것을 전제로 합니다.
- **메신저 알림(선택):** 서버 환경 변수 `ALERT_WEBHOOK_URL`에 Slack 또는 Discord 수신 웹훅 주소를 넣으면 감지 즉시 운영자에게 메시지가 갑니다. 메시지에는 세션(멘토·일정), 신청번호, 유형, 발언 일부, 사유만 담기고 **학생 이름은 포함되지 않으며** 발언 속 전화번호·메일은 가려집니다. 웹훅 전송이 실패해도 요약은 정상 동작합니다.
- **개인정보:** 음성과 전체 원문은 저장하지 않고, 감지된 경우에만 짧은 발언 일부가 남습니다. 녹음 동의 문구에도 이 내용을 안내합니다. 자해·위기 표현이 감지되면 녹음한 사람에게 청소년전화 1388 안내를 보여줍니다.
- **시연 제한:** 알림 목록은 브라우저(localStorage)에 저장되므로 같은 브라우저의 운영자 페이지에서만 보입니다. 서로 다른 기기의 알림을 한곳에서 모으려면 서버 저장소(DB)가 필요하며, 지금은 웹훅이 그 역할을 대신합니다.

## 채팅 부적절 표현 감지 (시연 버전)
채팅 메시지를 보낸 **뒤에** 서버(`app/api/moderate-chat/route.ts`)가 한 건씩 점검하고, 문제가 있으면 수업 녹음 감지와 같은 운영자 "안전 알림"(과 `ALERT_WEBHOOK_URL` 메신저 알림)으로 보냅니다. 전송을 막지는 않습니다.
- **두 단계 점검:** ① 전화번호·SNS·오픈채팅·"따로 만나자" 같은 외부 연락·만남 유도는 규칙으로 즉시 감지합니다(AI 없이 동작). ② 비속어·모욕·괴롭힘·성적 표현·폭력·자해 신호 등은 OpenAI가 맥락을 보고 판단합니다. AI가 실패하거나 키가 없으면 ①만 동작합니다.
- **기존 보호 유지:** 팀원이 만든 전화번호 전송 차단과 외부 메신저 주의 안내는 그대로 두었고, 그 위에 운영자 알림이 추가됩니다.
